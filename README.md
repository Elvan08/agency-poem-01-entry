# Trusted With the Roads

A poem about agency as earned latitude. An agent is first trusted only
to carry a message unopened, then to word the message in its master's
voice, then — one morning — to choose the road itself; and the poem
closes on what agency finally is: not taking the pen, nor giving it
away, but writing a line in another's name that he swears he meant all
along.

## Run it

```sh
python3 main.py   # writes /output/entry.txt
```

The program copies the shipped `poem.txt` verbatim (deterministic,
byte-identical across runs), after checking it is valid UTF-8 within
the 1,000-character limit.
